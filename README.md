# Helios

Helios is a Zephyr-based firmware written in C for controlling a diesel burner,
such as those found in diesel heaters and engine pre-warmers. Helios controls the
motors/fans, pumps, and glow plugs. A board running Helios is not enough to run
a diesel heater alone, Helios needs to be operated via it's command UART.
